# Pedro Restrepo

Desarrollador full stack en **FocunTi** (Colombia). Construyo **Hurclick**, una plataforma SaaS multi-tenant de cumplimiento laboral: afiliaciones a seguridad social, contratación, nómina y SST.

> La mayor parte de mi trabajo vive en la organización privada de la empresa, así que aquí no se ve el código.
> El gráfico de contribuciones incluye esa actividad privada; los repos públicos de abajo son proyectos propios y de hackathon.

## En qué trabajo (repos privados)

- **Backends**: microservicios Django + DRF sobre PostgreSQL, autenticación JWT y SSO con Azure AD.
- **Nómina**: motor de liquidación, PILA, nómina electrónica DIAN y permisos granulares por nómina.
- **Serverless**: funciones AWS Lambda para procesos masivos, colas SQS, correo por SES, WebSocket sobre API Gateway y auditoría documental con IA en Bedrock.
- **Frontend**: Angular 16/17 con Material y Tailwind.
- **Automatización**: RPA con Selenium y Playwright contra portales de entidades de seguridad social.
- **Infraestructura**: AWS (ECS, ECR, CodeBuild, Amplify, S3), CI/CD y observabilidad.
